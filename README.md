# 악역영애 말포이: 은빛 서약

[게임 플레이](https://ipjaworld.github.io/malfoy-silver-vow/)

비상업적 개인 학습·기술 실험용 팬 비주얼 노벨. 공식 해리 포터 게임이 아닙니다. 원작 이름과 설정을 활용한 새 시나리오이며 공식 대사·음악·일러스트는 포함하지 않았습니다.

세 장, 15개 장면, 아홉 서약. 각 장의 서약 3개를 모두 모으면 다음 장이 열립니다. 첫 방문에 이름을 정하고, 신뢰·단서·용기에 따라 추가 대화와 선택지가 달라집니다. 클릭/Enter/Space로 진행하고 1–3으로 선택합니다. 저장은 브라우저에 보관되며 기기 간 동기화는 없습니다.

공개 정적 게임 배포본입니다. 이메일 인증이나 계정 정보는 포함하지 않습니다. 게임 아트는 새 AI 생성 캐릭터와 자체 SVG 배경, 음악은 자체 합성입니다.
